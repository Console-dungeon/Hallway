# Wprowadzenie

**Hallway** to system do zarządzania wspólnotą mieszkaniową i zgłoszeniami mieszkańców.

## Z czego składa się projekt

| Część        | Technologia                  | Opis                                   |
| ------------ | ---------------------------- | -------------------------------------- |
| `apps/web`   | Next.js, shadcn/ui, Tailwind | Panele mieszkańca, pracownika i admina |
| `apps/api`   | Fastify, Zod, OpenAPI        | REST API pod `/api`                    |
| `apps/docs`  | Nextra                       | Ta dokumentacja (statyczny eksport)    |
| `packages/*` | TypeScript                   | Wspólne configi, schemat bazy, typy    |

> Ta strona jest szkieletem – treść dokumentacji rozwija Filip.
